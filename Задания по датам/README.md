# Задания по датам

Каждая подпапка названа в формате **«Задание за ДД.ММ.ГГГГ — тема»**. Это навигация по этапам курса для показа преподавателю.

Исполняемый исходный код не дублируется в каждой подпапке: он находится в корне решения, чтобы не было нескольких разных версий проекта.

- API и модель данных: `../KooliProjekt.Application` и `../KooliProjekt.WebApi`.
- Тесты: `../KooliProjekt.Application.UnitTests` и `../KooliProjekt.IntegrationTests`.
- Клиенты: `../KooliProjekt.WindowsForms`, `../KooliProjekt.WpfApplication`, `../KooliProjekt.BlazorWASM`, `../KooliProjektAngular`.
- Диаграмма и документация: `../Documentation`.

Полный порядок запуска указан в `../README.md`.
