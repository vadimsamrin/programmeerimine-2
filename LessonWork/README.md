# Course work by lesson date

`KooliProjekt.sln` is the single evolving solution. The dated folders below contain the documentation, test evidence and lesson-specific artefacts for each stage. This avoids maintaining several conflicting copies of the same application.

| Date | Lesson focus | Artefacts placed here |
|---|---|---|
| 2025-10-03 | .NET and ASP.NET Core tutorials | Setup notes and tutorial links |
| 2025-10-10 | Data model and documentation | Diagram and table documentation |
| 2025-10-17 to 2025-11-28 | EF Core, handlers, repositories | API implementation and migration notes |
| 2026-01-16 to 2026-02-19 | Unit tests and integration tests | Test classes and reports |
| 2026-02-26 to 2026-04-30 | WinForms and WPF | Desktop client implementation and tests |
| 2026-05-07 to 2026-05-15 | Blazor WASM and Angular | Web clients and build notes |

The final project and all executable source code are in the parent directory. Each dated folder is filled as the corresponding lesson artefact is completed and verified.
